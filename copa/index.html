Código da partida — passe só para os dois competidores

Como funciona

1. Monte o campeonato com os nomes e a meta. Vagas que sobrarem na chave viram passe direto (W.O.).

2. Clique numa partida → Código da partida. Passe o código (ou o link) só para os dois competidores. Eles abrem ursusman.com/copa/jogar, digitam o código e escolhem o próprio nome.

3. Quando os dois estiverem conectados, clique em Iniciar partida. Acompanhe ao vivo no pop-up — o vencedor avança sozinho na chave.

  • Vence quem chegar na meta primeiro. Se os dois passarem na mesma rodada, vence quem tiver mais pontos; empate vai para rodada extra.
